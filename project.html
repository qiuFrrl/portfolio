Domore (Robodesk)

Domore is a smart desk companion designed to accompany you while working on assignments or studying. It features various functions such as weather information, a digital clock, an interactive robot character, and a messaging feature that allows you to communicate with friends who also own a Domore device.

Website for Domore

Web for Domore is a dedicated website developed to support the Domore device. It allows users to enter their Wi-Fi credentials so the device can connect to the internet and store the required network information. The website also provides a platform for users to send messages and images to their friends who have a Domore device.

Drone

A F450 quadcopter with a custom flight controller powered by an ESP32 microcontroller. This drone is developed primarily as a learning and experimentation project, focusing on gesture-based control using a smart glove. The glove is equipped with a gyroscope sensor to detect hand movements and translate them into control inputs for the drone. Unlike conventional drones, this project is designed to be controlled without a traditional remote controller. This project is currently under development.
